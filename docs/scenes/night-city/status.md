# 씬 2 — 나이트시티 (동결)

```
web/?scene=night-city
```

사이버펑크 야간 도시. 프리캠 전용. **이 씬은 동결이다** — 작업 계획이 없고,
다시 열지 않는다 (2026-08-03 사용자 결정으로 백로그 전부 폐기, 일지도 정리).
씬은 저장소 규약대로 빌드 가능한 상태로 보존한다.

```

감사 경고 0 · 배치 검사 결함 0 · 검증 뷰 26개
```

## 알려진 한계 (동결 상태 그대로 둔다)

- **26뷰가 재현되지 않는다.** 같은 코드로 두 번 찍으면 픽셀 차이값이 매번
  다르다 — 씬 안의 무언가(교통·명멸 의심)가 `tick(time, 0)` 고정을 안 따르고
  실제 시간을 읽는 것으로 보인다. 그래서 **이 씬은 픽셀 회귀의 비교 대상이
  아니다.** core 를 고칠 때는 삼각형 수(4,203,303 정확 일치)로 무변경을 잰다.
- 지형이 완전 평지고, 형태 어휘가 상자·원기둥 계열뿐이다.
- `rooftop.js` + `towers.podium/shaft` + `massing.*` 의 공통 타워 경로는
  한 번도 돌지 않는 죽은 경로다.
- 시설물끼리의 겹침은 배치 검사가 안 본다 (`overlappingPairs` 를 `fixture`
  에 걸면 나오게 되어 있다 — 안 걸어 둔 상태로 동결).
