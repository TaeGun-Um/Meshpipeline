# 씬 1 — 주택가 공터 (동결 · 파이프라인 기준 씬)

```
web/?scene=vacant-lot
```

낮 · 3인칭 · 이 저장소의 **기준 씬**이다. 좌표계·조명 규약을 여기서 실측으로
확정했고, 익스포트 파이프라인 79항목이 여기서 통과했다. **동결이지만 특별한
역할이 있다** — 파이프라인(GLB→블렌더→유니티)이 이 씬의 오브젝트를 기준으로
돌므로, 규약 회귀를 재현할 때는 이 씬을 쓴다.

## 동결 시점의 실측

```
삼각형 182,428 · 텍스처 63MB · 검증 뷰 2개 (close · wide)
오브젝트: ground · road · walls · houses · poles · props · weeds(인스턴싱) · character
캐릭터: 스켈레톤 + 보행 클립 (파이프라인이 스킨·애니메이션 왕복을 여기서 검증)
```

## 이 씬이 맡는 것

| | |
|---|---|
| **파이프라인 부트스트랩** | 클론 후 `__export` 로 뽑는 GLB 여덟 개가 이 씬 것이다 (README "클론 직후") |
| **규약의 실측 근거** | glTF→유니티 축 변환 · FBX 왕복 yaw · v축 방향 — 추측이 두 번 틀렸고 여기서 실측으로 확정했다 (`pipeline/contract.json`) |
| **core 회귀의 리트머스** | 그림자 켠 유일한 검증 씬. core 를 고치면 이 씬의 2뷰 픽셀 일치가 첫 관문이다 |
