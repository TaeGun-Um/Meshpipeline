# 게임 스토리 — 이 씬이 게임에서 하는 일 (2026-08-05 사용자 확정)

`facility.md` 가 "형태의 근거" 라면 여기는 **그 위의 근거** — 무엇을 위해
모델링하는가다. 소품·평면·파손을 정할 때 이 문서에 대고 판단한다.

---

## 1. 게임 개요

- **장르**: 크래프팅 + 서바이벌 + 어드벤처
- **세계관**: 알 수 없는 세상(차원)들이 지구와 연결됐다. 생물·구조물이
  서로의 차원을 침범하며 지구도 피해를 입어 황폐화됐다.
  판타지·공상과학·과학·마법이 혼합 가능한 세상이다.
- **주인공**: 회사에서 일하던 **일반인 A** — 특별한 능력이 없다. 생존하며
  세계의 비밀을 밝혀낸다. 멀티플레이 환경에서는 B·C·D 가 추가된다.

## 2. 오프닝 시퀀스 — 이 씬이 무대다

```
1  A 가 사무실에서 일하는 중 갑작스러운 커다란 지진
2  떨어지는 물건에 머리를 맞고 기절 -> 깨어남          <- 게임 시작 지점
3  사무실 문이 무언가로 막혀 있다
4  사무실 안의 아이템을 조합해 덕트를 연다
5  덕트를 타고 다른 방(예: 화장실)으로 이동
6  건물 밖으로 탈출 -> 황폐화된 외부 세계와 조우        <- 다음 씬으로
```

## 3. 모델링 목표 — 스토리에서 도출

| # | 목표 | 지금 상태와의 거리 |
|---|---|---|
| 1 | **시작 사무실 방** — 인트로(지진 전)의 정갈한 배치와 깨어난 뒤의 파손 상태, **전/후 두 벌** (이 방만 — 나머지 층은 파손 한 벌이 기본 상태다). 쓰러진 소품 · 떨어진 물건(머리를 맞은 그것) · **잔해로 막힌 문** · 조합 재료가 눈에 띄게 배치 | 문짝 자체가 아직 없다 (status.md 5.2). 파손·먼지도 백로그 — 이 스토리로 **우선순위가 확정**됐다 |
| 2 | **덕트 = 탈출 루트** — 장식이 아니라 길이다. 점검구/급기구 커버(상호작용으로 열림) · 사람이 기어갈 단면 · 방과 방을 잇는 덕트 그래프 | 지금 덕트는 복도 장식이다. 다만 천장 위 설비 공간(슬래브 0.35 위)이 이미 설계에 있어 (facility.md 2.1) 기반은 있다 |
| 3 | **경유 방(화장실 등)** — 덕트로 도착하는 생활 공간 | 평면에 화장실이 없다. **176㎡ 방 넷 쪼개기와 한 작업**이다 — 쪼갤 때 화장실·탈출 경유 공간을 넣는다 |
| 4 | **아이템 조합 재료** — 파괴 드롭 부품 · 약탈 아이템 | 상호작용 분리(노드 353) · 약탈 포즈(229) 가 이미 이 목표의 기반이다 |
| 5 | **지진 파손** — 떨어진 천장 타일 · 넘어진 선반 · 금 간 벽 · 흩어진 소품 · 죽거나 깜빡이는 등 | "너무 깨끗하다" 백로그가 **지진 직후**로 구체화됐다 |
| 6 | **탈출구 = 씬 경계** — 건물 밖(황폐화된 세계)은 다음 씬이다 | 이 씬은 실내까지만 책임진다 |
| 7 | (멀티) 캐릭터 B·C·D | 캐릭터는 다이나믹 경로 — model-test 동결 지식이 출처. 지금은 안 한다 |

## 4. 무대 설정 — 지상 회사 건물 (2026-08-05 사용자 확정)

원래 지하 500m 연구시설(GATE Cascade)로 시작한 씬이지만, 스토리의
"회사 → 건물 밖 탈출 → 황폐화된 외부 조우" 에 맞춰 **지상 회사 사옥의
사무 층**으로 전환한다. A 는 평범한 회사원이고, 탈출하면 바로 바깥이다.

전환이 형태에 요구하는 것 (작업 목록은 status.md 5.2):

| | 지하 시절 | 지상 사옥 |
|---|---|---|
| 외곽 | 암반 껍데기 | **외벽 + 창문** — 창밖은 황폐화된 외부(뿌연 하늘·실루엣) |
| 중앙 홀 | 트램이 서는 플라자 | **로비/아트리움** — 트램 승강장 백로그는 폐기 |
| 지선 복도 | 트램 지선 | **비상계단·엘리베이터 홀** — 건물 밖 탈출구가 여기 선다 |
| 조명 | 인공조명이 전부 | 지진 후 **정전/비상 전원**이 기본 상태 — 인공조명 중심은 유지되고, 창이 두 번째 광원이 된다 |
