# 게임 스토리 — 이 씬이 게임에서 하는 일 (2026-08-05 사용자 확정)

`facility.md` 가 "형태의 근거" 라면 여기는 **그 위의 근거** — 무엇을 위해
모델링하는가다. 소품·평면·파손을 정할 때 이 문서에 대고 판단한다.

---

## 1. 게임 개요

- **장르**: 크래프팅 + 서바이벌 + 어드벤처
- **세계관**: 알 수 없는 세상(차원)들이 지구와 연결됐다. 생물·구조물이
  서로의 차원을 침범하며 지구도 피해를 입어 황폐화됐다.
  판타지·공상과학·과학·마법이 혼합 가능한 세상이다.
- **주인공**: 회사에서 일하던 **일반인 A** — 특별한 능력이 없다. 생존하며
  세계의 비밀을 밝혀낸다. 멀티플레이 환경에서는 B·C·D 가 추가된다.

## 2. 오프닝 시퀀스 — 이 씬이 무대다

```
1  A 가 사무실에서 일하는 중 갑작스러운 커다란 지진
2  떨어지는 물건에 머리를 맞고 기절 -> 깨어남          <- 게임 시작 지점
3  사무실 문이 무언가로 막혀 있다
4  사무실 안의 아이템을 조합해 덕트를 연다
5  덕트를 타고 다른 방(예: 화장실)으로 이동
6  건물 밖으로 탈출 -> 황폐화된 외부 세계와 조우        <- 다음 씬으로
```

## 4. 무대 설정 — 사옥 **지하 1층** (2026-08-05 사용자 확정)

원래 지하 500m 연구시설(GATE Cascade)로 시작해 잠시 지상 사무층으로
전환했다가, 같은 날 **회사 사옥의 지하 1층(전산·설비 층)** 으로 확정했다.

**A 가 살아남은 이유가 이 층이다.** A 는 서버관리부서 직원이고, 지진이
덮쳤을 때 지하 1층 사무실(서버관리부서)에 있었다 — 지상부가 무너지고
황폐화되는 동안 지하는 버텼다. 그래서 이 층에는 서버룸(전산실)과 그것을
관리하는 부서, 설비실·창고가 함께 산다. 시작 방 officeN3 이 그 서버관리부서
사무실이다 (use 'start').

| | 함의 |
|---|---|
| 외곽 | **창이 없다** — 벽 너머는 매립·암반이다. 지상 전환 때 냈던 외곽 창은 걷어냈다 (창 내는 법은 히스토리에 남는다) |
| 중앙 홀 | 플라자 = 지하층의 공용 홀. 엘리베이터·계단이 잇닿는 목적지 |
| 지선 복도 | **비상계단** — 지상으로 **올라가는** 탈출구가 여기 선다. 황폐화된 외부와의 조우는 지상에 오른 뒤(다음 씬) |
| 조명 | 하늘빛이 원래 없는 층이다. 인공조명이 전부고, 지진 후 정전/비상 전원 연출은 파손 단계에서 |
| 덕트 | 벽에 뚫린 환기구로 **수평으로 기어드는** 길 — 오르내리는 샤프트가 아니다 (facility.md 2.5) |
